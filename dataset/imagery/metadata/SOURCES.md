# Imagery dataset — sources, verification, and limitations

Acquired 2026-11-15. Everything below was checked empirically this session
(curl requests, byte-size comparison across dates, and direct visual
inspection of every downloaded image) — nothing here is assumed from
documentation alone.

## Sources investigated

| Source | Outcome | Why |
|---|---|---|
| **ISRO MOSDAC** (INSAT-3D/3DR/3DS) | **Skipped — login required** | Raw L1B/L1C granule download (HDF5/NetCDF) needs a MOSDAC Single Sign-On account; the download API itself refuses without valid credentials. No public, unauthenticated bulk-download path exists. Per instructions, not created/worked around. |
| **NASA GPM IMERG raw swath/grid data** (via NASA Earthdata/CDS, the path `dataset/scripts/normalize_gpm_imerg.py` was written for) | **Skipped — login required** | Needs a NASA Earthdata login; none exists locally (same situation documented earlier in this project for ERA5/GPM). |
| **NASA GIBS** (Global Imagery Browse Services) — WMS GetMap, `gibs.earthdata.nasa.gov/wms/epsg4326/best/wms.cgi` | **Used — no login needed** | Verified with plain `curl`: valid PNGs returned with no API key, for both `MODIS_Terra_CorrectedReflectance_TrueColor` / `MODIS_Aqua_CorrectedReflectance_TrueColor` (true-color reflectance) and `IMERG_Precipitation_Rate_30min` / `IMERG_Precipitation_Rate` (GPM IMERG, pre-colorized precipitation rate). These are **pre-rendered browse images**, not raw geophysical arrays — fine for image/video processing, not a substitute for the raw-swath ML pipeline. |
| **VIIRS_SNPP_CorrectedReflectance_TrueColor** (GIBS) | **Tried, dropped** | Returned an identical 4,981-byte, fully black image for every date tested (2026-11-07, -10, -12, -13, -14) at this bbox — a no-data tile, not real content. Rather than keep it and mislabel a blank tile as a "real sample", it was dropped; `MODIS_Aqua_CorrectedReflectance_TrueColor` was used instead for sensor diversity. |
| **NASA Worldview** | Not used directly | Worldview is the web UI built on the same GIBS WMS/WMTS backend used above; no separate data was pulled from it. |
| **IMD (India Meteorological Department) radar** | **Skipped — no public access found** | No public, unauthenticated API or bulk-download endpoint for IMD Doppler radar imagery was found (consistent with the IMD provider investigation already documented for the weather pipeline — `app/services/providers/imd.py`, gated behind an API key this project doesn't have). `dataset/imagery/radar/` is intentionally empty; this is a documented gap, not worked around with a substitute. |

## What was downloaded (18 files, `dataset/imagery/satellite/`)

Every file has a matching JSON sidecar in `dataset/imagery/metadata/` with the
exact source URL, timestamp, bbox, and license — generated by
`dataset/scripts/fetch_gibs_imagery.py`, re-runnable at any time.

- **7 daily true-color frames**, `MODIS_Terra_CorrectedReflectance_TrueColor`, one per day 2026-11-08 → 2026-11-14, same Delhi-NCR bbox. Visibly shows the real haze/smog typical of Delhi in November (confirmed by eye on the first frame — a visible Yamuna river trace through grey haze).
- **1 same-day second-sensor frame**, `MODIS_Aqua_CorrectedReflectance_TrueColor`, 2026-11-14 (Aqua's overpass is several hours after Terra's — a genuine same-day, different-time comparison pair, not a duplicate).
- **10 consecutive half-hourly frames**, `IMERG_Precipitation_Rate_30min`, 2026-08-05T07:00Z → 11:30Z. This exact window was chosen *because* it was manually probed first (12+ candidate timestamps across the day) and confirmed to show real, evolving, non-trivial rain — not picked blindly. Two sample frames were visually compared before acquisition: 07:00Z shows scattered green/yellow cells, 11:00Z shows a newly-developed heavy red cell in the south — genuine precipitation movement, not noise.

**Bounding box** (all assets): `26.8,76.5,29.2,78.3` (EPSG:4326, lat/lon degrees) — covers Delhi, Gurugram, Noida, Faridabad, Ghaziabad, Meerut.

**License**: NASA data use policy — public domain / CC0 unless a layer states otherwise (none here do). Suggested acknowledgement (from `earthdata.nasa.gov/gibs`, quoted verbatim): *"We acknowledge the use of imagery provided by services from NASA's Global Imagery Browse Services (GIBS), part of NASA's Earth Science Data and Information System (ESDIS)."*

## Known limitations

- These are GIBS **browse images** (already color-mapped PNG), not raw calibrated reflectance/precipitation arrays — fine for the image-processing module (resize, denoise, contrast, optical flow, segmentation, time-lapse) but not a source for retraining any ML model.
- Polar-orbiting MODIS/Aqua only pass over Delhi-NCR roughly once a day each, so the **true-color** frames are a day-to-day (or same-day two-sensor) comparison set, not a fine-grained motion sequence.
- Only the **10-frame IMERG sequence** is treated as genuine "consecutive video frames" — it is the only set verified to be closely time-spaced over real, evolving conditions. Nothing else in this dataset is presented as a video sequence.
- No ground-based radar imagery exists in this dataset (see table above) — the frontend's radar viewer (if built) must visibly show "no data" for Delhi-NCR radar, never a substitute.
- Sample size is intentionally small (18 stills, ~3.9 MB total) per the "do not download massive archives" instruction.
